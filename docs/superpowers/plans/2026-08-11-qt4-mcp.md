# QT4 Remote MCP MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Firebase-hosted MCP MVP for QT4 end users with user-scoped reads, review comments/hilos, resources for chatbots, audit logs, and pending confirmations.

**Architecture:** The Firebase Functions backend exposes a single HTTP MCP endpoint and validates Firebase ID tokens from `Authorization: Bearer`. The frontend adds a small authenticated MCP page where users can obtain connection information and review prepared sensitive actions.

**Tech Stack:** React 19, Vite, Firebase Auth, Firestore, Firebase Functions v2, Firebase Admin SDK, JSON-RPC-compatible MCP messages.

## Global Constraints

- Use Firebase ID tokens for the MVP.
- Do not expose arbitrary Firestore access.
- Never trust `actorId` from tool input.
- Store sensitive actions as pending confirmations instead of executing them.
- Log every MCP tool call and every non-silent fallback.
- Keep text files UTF-8 without BOM.
- Use English method names.
- Add route/file comments where new source files are created.
